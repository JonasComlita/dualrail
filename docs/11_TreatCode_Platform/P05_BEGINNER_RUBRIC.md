# P05 Beginner Learning Rubric

This rubric defines the human review required before P05 can be marked
complete. The automated content and learning-flow checks produce evidence for
each criterion; they do not replace educator approval.

## Review criteria

| Criterion | Pass condition | Evidence |
|---|---|---|
| Representation | A first-time reader can explain why numeric and lane encodings differ. | `representation-boundaries` page and boundary check |
| Progression | The beginner path is ordered and each page names prerequisites and a next step. | `learning-catalog.json` and content report |
| First program | A reader can edit the first TCL function in the browser and reach the challenge surface without local setup. | `first-tcl-program` code module and learning-flow report |
| Accuracy | Claims point to repository source and focused tests; numeric, lane, and hardware meanings are not conflated. | Per-page provenance and content report |
| Accessibility | Learning navigation, quizzes, code input, and source links have names, labels, and keyboard-accessible controls. | Accessibility report |
